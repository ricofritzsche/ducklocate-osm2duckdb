# ducklocate-osm2duckdb
An open-source DuckDB extension written in Rust that turns OpenStreetMap data into structured, queryable tables for roads, buildings, administrative areas and points of interest, with typed attributes, geometries and source references.

The development target is DuckDB 2.0. See [Concept.md](Concept.md) for the design
direction and open questions, and [AGENTS.md](AGENTS.md) for contributor-agent
instructions and the project skills.
