## Start with a small snapshot

The repository includes a synthetic roads fixture for a first query. The current
reader accepts inputs up to **512 MiB**, with additional record and index limits.
National-scale performance and geographic completeness have not been established.
The [Bremen evaluation](../bremen-roads-evaluation.md) records a small real-input
correctness and resource baseline.

There is **no community installation yet**. Getting started currently means building
and loading a local development artifact. Default reads need no Spatial extension;
reprojection and spatial functions have additional prerequisites.

## Where the project is going

DuckLocate is the family name. This project focuses on **OSM to DuckDB** through a
native Rust extension. A future `osm2duckdb` CLI is intended to share the same
projection implementation.

Additional profiles, named-region downloads, convenience import, and incremental
updates remain proposals. Follow the [roadmap](./project/roadmap.md) for the boundary
between current behavior and future direction.
