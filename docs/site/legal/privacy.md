## Website visits and hosting

The public website is designed for static hosting on GitHub Pages. This notice
describes that hosting arrangement; a local development preview is served from
the computer running the preview instead.

When you visit a GitHub Pages deployment, your browser sends GitHub the
technical information needed to request and deliver pages, such as your IP
address and HTTP request information. GitHub states that it logs and stores
visitor IP addresses for security, including for visitors who are not signed in.
The maintainer does not receive GitHub Pages' raw visitor access logs or run
visitor analytics.

The purpose of serving pages and handling security-related information is to
provide reliable documentation and protect the website from misuse. Where the
maintainer processes personal data for this purpose, the legal basis is the
legitimate interest in operating and securing the project website
(Article 6(1)(f) GDPR).

GitHub's own processing, recipients, retention criteria and international
transfer safeguards are described in the
[GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
GitHub identifies GitHub B.V. in the Netherlands and GitHub, Inc. in the United
States as relevant entities. It processes data internationally, including in
the United States, and describes safeguards including standard contractual
clauses and the EU–US Data Privacy Framework. GitHub determines its hosting-log
retention; the maintainer cannot set or promise a specific deletion period.
See also [GitHub Pages data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).

## Cookies, browser storage and search

The website has no advertising, tracking pixels, behavioural profiling,
analytics service, embedded maps or embedded social-media content. Fonts,
styles, scripts and search indexes are served with the website.

Starlight stores the display preference under `starlight-theme` in your
browser's local storage. It records light, dark or automatic display mode;
it is not a visitor identifier and is not sent to the maintainer. This
preference has no automatic expiry. You can change it using the theme selector
or remove it by clearing the website's browser storage. Starlight also stores
sidebar expansion state as `sl-sidebar-state` in session storage, which is
cleared when the tab session ends. Neither setting is used for tracking.

Search runs in your browser using the website's Pagefind index. Search queries
are not submitted to a separate search or analytics provider. Loading the index
still makes ordinary requests to the website host.

The current configuration uses browser storage only for interface functions
and preferences, so it does not present a tracking-consent banner. Spanish
regulator guidance distinguishes these uses from storage requiring consent;
see the [AEPD cookie guide](https://www.aepd.es/guias/guia-cookies.pdf).

## Correspondence and project participation

If you write to the maintainer, your name and reply address if supplied, message
and necessary correspondence details are used to answer your request and follow
up on the project matter you raised. Postal delivery providers handle letters
as needed to deliver them. Enough information to answer and a way to reply are
needed if you want a response. Messages are not used for marketing.

The legal basis is the legitimate interest in responding to enquiries and
maintaining an open-source project (Article 6(1)(f) GDPR), or compliance with a
legal obligation where one applies (Article 6(1)(c) GDPR). Routine private
correspondence is kept while needed to answer and follow up on the enquiry.
After the matter is resolved, it is deleted unless still needed for an ongoing
project matter, a legal retention obligation or the establishment, exercise or
defence of legal claims.

If you participate through GitHub issues, pull requests or commits, your public
profile, contribution and related discussion may be visible to anyone and
retained in the project history. The purpose and legitimate interest are
collaborative development, attribution and a reproducible development record
(Article 6(1)(f) GDPR). Relevant public contributions and discussions are kept
while they remain part of that record. Removal requests are assessed against
applicable rights and the need to preserve attribution and legal records.
GitHub's own privacy terms also apply. Avoid including private information in
public reports; use the postal address above for private matters.

## Your rights

Subject to the conditions in the GDPR, you may request access, correction,
erasure or restriction of your personal data, object to processing based on
legitimate interests, and request portability where applicable. Where processing
depends on consent, you may withdraw that consent without affecting earlier
lawful processing. The project does not make automated decisions about you or
profile you.

Write to Rico Fritzsche at the postal address above to exercise your rights
regarding the maintainer's processing. Requests are answered within one month;
any lawful extension and its reason will be communicated within that month.
For GitHub's own processing, use the contact and rights mechanisms in its
privacy statement.

You may complain to the Spanish supervisory authority,
[Agencia Española de Protección de Datos (AEPD)](https://www.aepd.es/),
or another competent data-protection authority.
